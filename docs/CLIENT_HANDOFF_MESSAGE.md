# Текст для передачи клиенту ссылки подключения

Здравствуйте.

Мы подготовили для вашей компании доступ к системе «Память QR».

Перейдите по ссылке подключения и задайте свой пароль. Ссылка одноразовая и нужна только для первого входа.

После входа вы сможете:

- создать страницу памяти;
- добавить фотографии и историю;
- опубликовать страницу;
- скачать QR-код;
- передать ссылку семье.

Если ссылка перестанет работать, напишите нам — мы создадим новую.
