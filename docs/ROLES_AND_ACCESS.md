# Роли и доступы

## Super admin / Платформа

Назначение: владелец платформы.

Доступ:

- все партнёры;
- все бизнесы;
- аналитика платформы;
- аудит;
- health/release readiness;
- тарифы;
- создание invite-ссылок;
- редактирование бизнесов;
- отключение/архивация бизнесов;
- вход от имени клиента с логированием.

Ограничение: использовать только для администрирования платформы, не для ежедневной работы клиента.

## Partner / Партнёр

Назначение: партнёр, который подключает несколько ритуальных компаний.

Доступ:

- только свои бизнесы;
- аналитика по своим бизнесам;
- создание бизнесов в своём scope;
- редактирование параметров своих бизнесов;
- создание одноразовых invite-ссылок;
- вход от имени своих клиентов для поддержки.

Запрещено:

- видеть чужие бизнесы;
- видеть платформенные health/release-разделы;
- управлять тарифной матрицей платформы;
- удалять или архивировать бизнесы как критическое действие платформы.

## Business / Клиент

Назначение: менеджер или владелец ритуальной компании.

Доступ:

- главная админки;
- страницы памяти;
- CRM/заявки семьи;
- лендинг для семей;
- материалы;
- адрес страницы;
- публикация и QR;
- собственная аналитика.

Запрещено:

- видеть платформу;
- видеть партнёрскую админку;
- видеть чужие бизнесы;
- управлять чужими страницами памяти;
- создавать платформенные invite-ссылки.

## Тестовые логины локального стенда

После `npm run seed` доступны тестовые аккаунты для локальной проверки. Их нельзя использовать в production.

- `admin / change-me` — платформа.
- `partner / change-me` — тестовый партнёр.
- `manager / change-me` — тестовый бизнес.

В production демо-подсказки на странице входа должны быть скрыты.
