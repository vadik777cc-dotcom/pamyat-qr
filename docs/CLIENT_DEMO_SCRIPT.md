# Сценарий демонстрации клиенту — Память QR

Цель демонстрации: показать владельцу или менеджеру ритуальной компании, что он сможет создать страницу памяти, передать семье ссылку и получить QR-код без технических знаний.

## 1. Вход клиента

Покажите не общий логин и пароль, а безопасное подключение:

1. Платформа или партнёр создаёт бизнес.
2. Система создаёт одноразовую ссылку подключения.
3. Клиент открывает ссылку.
4. Клиент сам задаёт пароль.
5. Клиент попадает на экран «Первый запуск».

Что сказать клиенту:

> Мы не передаём пароли в переписке. Вы сами создаёте пароль по одноразовой ссылке. После первого входа ссылка больше не работает.

## 2. Главная админки

Покажите только ежедневные действия:

- создать страницу памяти;
- посмотреть заявки семьи;
- открыть материалы для общения с семьёй;
- открыть QR-комплект.

Не показывайте технические разделы без необходимости.

## 3. Создание страницы памяти

Путь показа:

1. Открыть «Страницы памяти».
2. Создать или открыть демо-страницу.
3. Заполнить ФИО, даты, короткую фразу, историю.
4. Добавить фото.
5. Сохранить.
6. Открыть предпросмотр.

Что сказать клиенту:

> Страницу можно заполнить сразу минимально, а фотографии и историю добавить позже.

## 4. Публикация и QR

Путь показа:

1. Открыть вкладку публикации.
2. Опубликовать страницу.
3. Открыть публичную ссылку.
4. Скачать QR-код.

Что сказать клиенту:

> QR-код можно использовать на табличке, в макете, на памятнике или в документах для семьи.

## 5. Лендинг для семей

Покажите первый экран лендинга и объясните:

- семья видит услугу простыми словами;
- компания указана как партнёр;
- можно перейти к созданию страницы памяти или связаться с компанией.

## 6. Материалы для менеджера

Покажите раздел «Материалы»:

- готовая фраза для объяснения услуги семье;
- текст рядом с QR-кодом;
- список материалов, которые нужно попросить у семьи.

## 7. Завершение демонстрации

Финальный порядок:

1. Клиент увидел админку.
2. Клиент увидел страницу памяти.
3. Клиент увидел QR.
4. Клиент понял, что технические настройки ему не нужны.

Контрольная фраза:

> Ваша ежедневная работа — создать страницу, добавить материалы семьи, опубликовать и получить QR. Остальные технические вещи можно не трогать.
