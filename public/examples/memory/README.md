# Птица Памяти — страница памяти

Версия v15 добавляет экран «Семейный альбом» после страницы «История жизни».

## Структура
- `index.html` — вся страница, стили и JS.
- `assets/hero-portrait-bg.webp` — фото человека для hero.
- `assets/memory-candle.webp` — статичная свеча.
- `assets/svecha.mp4` — видео свечи после зажжения.
- `assets/olive-branch.svg` — декоративная веточка.
- `assets/album-1.webp` … `assets/album-6.webp` — фотографии семейного альбома.

## Что есть
1. Hero с портретом, свечой и сохранением состояния зажжённой свечи.
2. Экран «Тёплые слова близких» с формой отправки слов семье.
3. Экран «История жизни».
4. Экран «Семейный альбом» с реализуемой мозаикой фото и lightbox-просмотром.

## Замена фотографий альбома
Можно заменить файлы `assets/album-1.webp` … `assets/album-6.webp` своими фото, сохранив имена файлов.
Подписи меняются в `index.html` в `figcaption` и `data-caption`.

## v20: семейный альбом как бережная карусель

Альбом теперь не использует мозаичную сетку, потому что реальные семейные фото часто бывают разного размера и качества. Основной экран показывает одно большое фото целиком через `object-fit: contain`, без обрезки и без белых рамок. Перелистывание работает через мягкое исчезновение/появление фото и подписи.

Файлы фотографий лежат в `assets/album-1.webp` ... `assets/album-6.webp`. Для продакшена лучше отдавать оптимизированные preview-файлы шириной примерно 1600–2200px, а не оригинальные 4K/сканы напрямую. В полноэкранном режиме доступна лента миниатюр.


## Альбом v21

Альбом теперь оформлен как архивный лист: одно большое фото показывается полностью без обрезки через `object-fit: contain`, без белых рамок. В открытом полноэкранном альбоме фото также отображаются напрямую на затемнённом фоне без светлой карточки-подложки.

Для загрузки через админку рекомендуется сохранять preview-файлы до 1800px по длинной стороне и WebP/JPEG с разумным качеством, чтобы не отдавать на страницу 4K-оригиналы.

## v25 album notes

Альбом теперь построен как стабильная сцена для фотографий любых пропорций:
- основная область фото имеет постоянный размер;
- само фото показывается через `object-fit: contain` и не должно обрезаться;
- за фото используется слабый blur-backdrop из той же фотографии, чтобы вертикальные и квадратные кадры не выглядели случайно маленькими на пустом фоне;
- элементы управления находятся в нижней строке и не привязаны к размеру конкретного фото;
- в полноэкранном режиме убраны белые рамки/карточки, фото также отображается через `contain`.

Для админки рекомендуется готовить три версии каждого изображения: `thumb`, `preview`, `large`. На страницу подставлять `preview`, в полноэкранный альбом — `large`, в миниатюры — `thumb`.
